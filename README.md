# 🏢 Proyecto: CRM Inmobiliario – APM INVERSIONES

## 📌 Contexto
Se desarrolló un sistema CRM orientado al sector inmobiliario, con el objetivo de digitalizar la gestión de clientes, propiedades y citas, reemplazando procesos manuales.

## ⚠️ Problema
La empresa no contaba con una plataforma centralizada, lo que generaba:
- Desorden en la gestión de clientes  
- Pérdida de información  
- Dificultad en el seguimiento de citas  

## 🛠️ Solución Técnica
- **UI/UX:** Diseño de interfaces con Figma (wireframes y prototipos)  
- **Frontend:** Desarrollo con React (componentes reutilizables)  
- **Maquetación:** HTML5, CSS3 (diseño responsivo)  
- **Control de versiones:** Git y GitHub  
- **Metodología:** Scrum  

## ✅ Resultado
- Sistema funcional para gestión de clientes y citas  
- Mejora en la organización de la información  
- Interfaz amigable para el usuario  
- Optimización de procesos internos

# 🌐 Proyecto: Sistema de Autenticación y Blog

## 📌 Contexto
Desarrollo de una aplicación web enfocada en la gestión de usuarios y publicación de contenido tipo blog.

## ⚠️ Problema
Se requería:
- Implementar autenticación de usuarios  
- Organizar contenido dinámico de forma eficiente  

## 🛠️ Solución Técnica
- **Frontend:** React (estructura modular)  
- **Lenguajes:** JavaScript, HTML5, CSS3  
- **Autenticación:** Login y registro con validaciones  
- **Despliegue:** Vercel  
- **Control de versiones:** Git y GitHub  

## ✅ Resultado
- Aplicación web desplegada y funcional  
- Sistema de autenticación operativo  
- Organización eficiente del contenido  
- Mejora en habilidades frontend
